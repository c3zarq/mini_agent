# T024 — Implementar preparação de contexto

**Etapa:** P05 — Sistema de arquivos e gerenciamento de contexto  
**Status:** Pendente

## Objetivo

Implementar a preparação das informações necessárias para envio ao modelo, organizando o contexto ativo da aplicação de acordo com a interação atual.

## Atividades

1. Examinar a arquitetura e os módulos existentes relacionados ao contexto.
2. Definir quais informações devem compor o contexto de uma requisição.
3. Implementar a organização das mensagens da conversa.
4. Integrar informações do projeto atual e seu progresso na EAP, conforme necessário.
5. Integrar conteúdos de arquivos consultados pelo agente, quando solicitados.
6. Preparar a estrutura de mensagens no formato esperado pela API do Ollama.
7. Criar testes automatizados para validar a preparação do contexto.

## Resultado esperado

As informações relevantes para cada interação são organizadas em uma estrutura de mensagens compatível com o modelo, permitindo que o agente utilize dados da conversa, do projeto e de arquivos consultados sob demanda.
