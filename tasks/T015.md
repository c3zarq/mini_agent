# T015 — Definir formato da EAP

**Etapa:** P04 — Gerenciamento de projetos e tarefas  
**Status:** Concluída

## Objetivo

Definir e documentar um formato padronizado para os arquivos EAP.md, permitindo que o Mini Agent interprete automaticamente as etapas e tarefas de um projeto.

## Atividades

1. Definir a estrutura geral do documento Markdown.
2. Padronizar a identificação das etapas utilizando códigos P01, P02 etc.
3. Padronizar a identificação das tarefas utilizando códigos T001, T002 etc.
4. Definir a sintaxe dos títulos das etapas.
5. Definir a sintaxe das linhas das tabelas que identificam as tarefas.
6. Estabelecer regras para identificação única e estável de etapas e tarefas.
7. Definir um exemplo de referência de arquivo EAP.md.
8. Documentar o formato adotado em docs/ARQUITETURA.md.

## Critérios de conclusão

- O formato Markdown está documentado.
- Etapas e tarefas possuem identificadores padronizados.
- A estrutura permite distinguir etapas de tarefas.
- Os identificadores são estáveis e únicos dentro do projeto.
- Existe um exemplo de referência.
- O formato é compatível com a arquitetura definida para o Mini Agent.

## Implementação

- Padronizada a identificação das etapas pelo formato P01, P02 etc.
- Padronizada a identificação das tarefas pelo formato T001, T002 etc.
- Definidas tabelas Markdown como estrutura de identificação das tarefas.
- Estabelecidas regras para identificadores únicos, permanentes e não reutilizáveis.
- Documentado o formato em `docs/ARQUITETURA.md`.
- Verificada a compatibilidade com a estrutura existente em `docs/EAP.md`.
