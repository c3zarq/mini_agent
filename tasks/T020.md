# T020 — Implementar validação de caminhos

**Etapa:** P05 — Sistema de arquivos e gerenciamento de contexto  
**Status:** Concluida

## Objetivo

Implementar um mecanismo de validação de caminhos que restrinja o acesso do agente aos arquivos e diretórios pertencentes ao projeto autorizado, impedindo acessos externos ou tentativas de escapar do diretório por meio de caminhos relativos, absolutos ou links simbólicos.

## Atividades

1. Analisar os recursos disponíveis no módulo `node:path` e no módulo `node:fs`.
2. Definir uma função responsável por validar caminhos em relação ao diretório raiz do projeto.
3. Implementar a resolução e normalização dos caminhos informados.
4. Verificar se o caminho resolvido pertence ao diretório autorizado.
5. Implementar a verificação de caminhos que utilizem referências relativas, como `../`.
6. Implementar a verificação de caminhos absolutos externos ao projeto.
7. Identificar e impedir acessos externos por meio de links simbólicos.
8. Implementar o tratamento de caminhos inválidos, inexistentes e erros de acesso.
9. Criar testes automatizados para verificar os diferentes cenários de validação.

## Critérios de conclusão

- Existe uma função responsável pela validação de caminhos.
- Caminhos pertencentes ao diretório autorizado são aceitos.
- Caminhos externos ao projeto são rejeitados.
- Tentativas de escapar do diretório utilizando `../` são rejeitadas.
- Caminhos absolutos externos ao projeto são rejeitados.
- Links simbólicos que apontem para locais externos são rejeitados.
- Caminhos inexistentes e entradas inválidas são tratados adequadamente.
- O mecanismo funciona utilizando os recursos nativos do Node.js.
- Os testes automatizados são aprovados.

## Restrições

- Utilizar Node.js e JavaScript com CommonJS.
- Utilizar os módulos nativos `node:path` e `node:fs`.
- O diretório raiz do projeto deverá ser a referência para todas as validações.
- A validação deverá considerar os caminhos reais do sistema de arquivos, incluindo links simbólicos.
- Não permitir acesso a arquivos externos ao projeto autorizado.
- Não implementar ainda listagem, pesquisa ou leitura de arquivos, que pertencem às tarefas seguintes.
- Manter a implementação modular e reutilizável.

## Implementação

Foi criado o módulo `src/files.js`, responsável pela validação de caminhos do sistema de arquivos.

Foi implementada a função `validatePath(projectRoot, requestedPath)`, com as seguintes responsabilidades:

1. Validar os argumentos recebidos.
2. Resolver o caminho físico real do diretório raiz autorizado utilizando `fs.realpathSync()`.
3. Resolver o caminho solicitado utilizando `path.resolve()`.
4. Identificar o caminho físico real do destino, considerando eventuais links simbólicos.
5. Verificar se o destino pertence ao diretório autorizado utilizando `path.relative()`.
6. Rejeitar caminhos externos ao projeto.
7. Tratar caminhos inexistentes, entradas inválidas e erros de acesso.

A função retorna um objeto com `success` e, quando a validação é aprovada, o caminho absoluto validado em `path`.

A implementação permanece modular e utiliza exclusivamente recursos nativos do Node.js.
