# T040 — Implementar comandos de projeto e tarefas

**Etapa:** P08 — Interface e acompanhamento do projeto  
**Status:** Concluída

## Objetivo

Implementar comandos na interface de terminal para permitir a consulta dos projetos cadastrados, a visualização das tarefas disponíveis e a seleção de uma tarefa para utilização como contexto pelo agente.

## Implementação

### `src/database.js`

- Implementada a função `listTasks(projectId)`.
- Validação do identificador do projeto.
- Verificação da existência do projeto.
- Consulta exclusiva das tarefas ativas.
- Ordenação por etapa, posição e código.
- Tratamento de erros de consulta.

### `src/cli.js`

- Implementados os comandos internos `/projetos`, `/tarefas` e `/tarefa`.
- `/projetos`: apresenta identificador, nome e diretório dos projetos cadastrados, identificando o projeto associado à sessão atual.
- `/tarefas`: apresenta código, título e estado das tarefas ativas do projeto atual.
- `/tarefa T018`: valida e seleciona uma tarefa pelo código.
- `/tarefa`: informa qual tarefa está selecionada.
- A seleção permanece em memória durante a execução da interface.
- O código selecionado é encaminhado ao `runAgent()` pelo parâmetro `taskCode`.
- Comandos internos não são encaminhados ao modelo.
- Implementada injeção de dependências para permitir testes isolados das consultas e do carregamento de tarefas.

### `tests/database.test.js`

Implementados testes para:
- Identificador de projeto inválido.
- Projeto inexistente.
- Consulta exclusiva de tarefas ativas.
- Ordenação das tarefas.
- Preservação do estado das tarefas.

### `tests/cli.test.js`

Implementados testes para:
- Listagem de projetos e identificação do projeto atual.
- Apresentação dos diretórios dos projetos.
- Listagem de tarefas.
- Seleção de tarefa válida.
- Encaminhamento do código selecionado ao agente.
- Rejeição de tarefa inexistente.
- Garantia de que comandos internos não sejam enviados ao agente.

## Testes

Testes específicos executados:

- `node --test tests/database.test.js` — aprovado.
- `node --test tests/cli.test.js` — aprovado.

Suíte completa:

- `npm test` — aprovada após as alterações.

Verificação sintática:

- `node --check src/cli.js` — aprovada.

## Resultado

A interface permite consultar projetos e tarefas, selecionar uma tarefa como contexto e utilizá-la nas interações seguintes com o agente.

A seleção não altera a persistência da sessão nem o estado das tarefas.

A implementação preserva a compatibilidade com `taskCode` em `runAgent()` e `buildContext()`.
