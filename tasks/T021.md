# T021 — Implementar listagem de arquivos

**Etapa:** P05 — Sistema de arquivos e gerenciamento de contexto  
**Status:** Concluida

## Objetivo

Implementar um mecanismo de listagem de arquivos e diretórios pertencentes ao projeto autorizado, permitindo consultar sua estrutura sem carregar automaticamente o conteúdo dos arquivos.

## Atividades

1. Analisar os recursos disponíveis no módulo `node:fs` para leitura de diretórios.
2. Definir uma função responsável por listar o conteúdo de um diretório.
3. Implementar a integração com a função `validatePath()` do módulo `files.js`.
4. Implementar a identificação de arquivos e diretórios.
5. Retornar os nomes, caminhos e tipos dos itens encontrados.
6. Implementar o tratamento de diretórios vazios e caminhos inválidos.
7. Garantir que a listagem não ultrapasse o diretório autorizado.
8. Criar testes automatizados para verificar os diferentes cenários de listagem.

## Critérios de conclusão

- Existe uma função responsável pela listagem de arquivos e diretórios.
- A listagem respeita o diretório raiz autorizado.
- Caminhos externos ao projeto são rejeitados.
- Arquivos e diretórios são identificados corretamente.
- Diretórios vazios são tratados adequadamente.
- Caminhos inválidos e erros de acesso são tratados.
- A listagem não percorre automaticamente toda a árvore de diretórios.
- Os testes automatizados são aprovados.

## Restrições

- Utilizar Node.js e JavaScript com CommonJS.
- Utilizar os módulos nativos `node:fs` e `node:path`.
- Reutilizar a função `validatePath()` implementada na T020.
- Restringir todas as operações ao diretório autorizado.
- Não implementar pesquisa ou leitura do conteúdo dos arquivos, que pertencem às tarefas seguintes.
- Manter a implementação modular e reutilizável.

## Implementação

Foi implementada a função `listFiles(projectRoot, requestedPath)` no módulo `src/files.js`.

A função utiliza `validatePath()` para verificar se o diretório solicitado pertence ao projeto autorizado.

A implementação utiliza `fs.readdirSync()` com a opção `withFileTypes: true` para identificar os itens do diretório.

Cada item retornado contém:

- `name`: nome do arquivo ou diretório.
- `path`: caminho absoluto.
- `type`: identificação como `file` ou `directory`.

A função também:

1. Verifica se o caminho validado corresponde a um diretório.
2. Retorna uma lista vazia quando o diretório não contém itens.
3. Rejeita caminhos inexistentes ou externos.
4. Trata erros durante a listagem.
5. Limita a operação ao conteúdo imediato do diretório, sem recursividade.

A função foi exportada pelo módulo `files.js`, juntamente com `validatePath()`.

## Testes

Os testes foram implementados em `tests/files.test.js`, utilizando o módulo nativo `node:test`.

Foram realizados seis testes específicos para a T021:
