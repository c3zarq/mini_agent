# T007 — Implementar envio de mensagens ao modelo

**Etapa:** P02 — Integração com Ollama  
**Status inicial:** Pendente

## Objetivo

Implementar o envio de mensagens a um modelo local por meio da API de conversação do Ollama.

## Escopo

1. Adicionar a função `chat()` ao módulo `src/ollama.js`.
2. Receber o nome do modelo e uma lista de mensagens.
3. Enviar uma requisição HTTP POST ao endpoint `/api/chat`.
4. Desativar o streaming de respostas.
5. Interpretar a resposta JSON do Ollama.
6. Retornar o conteúdo recebido e os dados da mensagem.
7. Tratar erros de comunicação, respostas HTTP inesperadas e parâmetros inválidos.

## Critérios de aceitação

- A função recebe um modelo e uma lista de mensagens.
- A requisição é enviada corretamente ao endpoint `/api/chat`.
- A resposta do modelo é retornada em uma estrutura acessível.
- Falhas são tratadas sem encerramento inesperado da aplicação.
- As funções anteriores são preservadas.
- Não são adicionadas dependências externas.

## Fora do escopo

- Histórico persistente de conversas.
- Streaming.
- Seleção automática de modelos.
- Processamento de respostas JSON estruturadas.
- Integração com o núcleo do agente.
