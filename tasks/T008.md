# T008 — Suporte a respostas JSON estruturadas

**Etapa:** P02 — Integração com Ollama  
**Status inicial:** Pendente

## Objetivo

Implementar suporte a respostas estruturadas em JSON na comunicação entre o Mini Agent e os modelos locais disponibilizados pelo Ollama.

## Atividades

1. Adaptar a função `chat()` para aceitar uma opção de resposta em formato JSON.
2. Utilizar o parâmetro `format` da API do Ollama.
3. Validar se o conteúdo retornado pelo modelo contém um JSON válido.
4. Converter o conteúdo recebido para um objeto JavaScript.
5. Tratar erros de formatação e respostas inválidas.
6. Preservar o funcionamento atual da comunicação em texto livre.

## Critérios de conclusão

- A função `chat()` continua funcionando normalmente sem solicitar JSON.
- É possível solicitar uma resposta em formato JSON.
- O conteúdo recebido é convertido corretamente para um objeto JavaScript.
- Respostas inválidas são tratadas sem interromper a aplicação.
