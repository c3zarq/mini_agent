# T043 — Implementar cálculo de progresso

**Status:** Concluída

## Objetivo

Implementar o cálculo do progresso geral do projeto e do progresso individual por etapa, utilizando os estados das tarefas armazenados no SQLite.

## Regras de cálculo

- Considerar somente tarefas ativas (`is_active = 1`).
- Considerar como concluídas somente tarefas com status `completed`.
- Calcular o percentual geral com base no total de tarefas ativas.
- Calcular o percentual individual de cada etapa.
- Atribuir peso igual a todas as tarefas.
- Manter etapas sem tarefas com percentual de 0%.
- Retornar 0% quando não houver tarefas, evitando divisão por zero.
- Não persistir percentuais no banco de dados.
- Utilizar o SQLite como fonte dos estados e a EAP como referência para a organização das etapas.

## Implementação

### `src/progress.js`

Novo módulo responsável pelo cálculo dos indicadores de progresso.

Implementa `calculateProgress(tasks, phases)`, com validação das estruturas recebidas, identificação de status inválidos, contabilização de tarefas ativas e cálculo dos percentuais geral e por etapa.

### `src/cli.js`

Implementa:

- `formatProgress(result)`: formata os indicadores para apresentação no terminal.
- Comando `/progresso`: consulta as tarefas do projeto atual, interpreta a EAP e apresenta os indicadores calculados.
- Injeção de dependência de `calculateProgress`, permitindo testes isolados.

O comando não aciona o agente nem modifica o estado das tarefas.

### `src/database.js`

Reutiliza a função existente `listTasks(projectId)` para consultar as tarefas ativas. Não foi necessária alteração no banco de dados.

### `src/tasks.js`

Mantido sem alterações. Sua responsabilidade permanece sendo a leitura e interpretação dos documentos individuais de tarefas.
