# T002 — Criar estrutura de diretórios

**Etapa:** P01 — Estrutura inicial<br>
**Dependência:** T001<br>
**Status inicial:** Pendente

## 1. Objetivo

Criar a estrutura de diretórios definida na Arquitetura Técnica do Mini Agent 0.1.

## 2. Estrutura prevista

```text
mini_agent/
│
├── docs/
│   ├── PRD.md
│   ├── ARQUITETURA.md

│
```

## 3. Instruções

1. Verificar os diretórios existentes.
2. Criar os diretórios ausentes.
3. Preservar os documentos e arquivos já existentes.
4. Não criar arquivos de código nesta tarefa.

## 4. Restrições

- Não instalar dependências.
- Não criar módulos JavaScript.
- Não modificar arquivos existentes.
- Não criar banco de dados.
- Não alterar a estrutura dos documentos.

## 5. Critérios de aceitação

- Diretórios docs, tasks, prompts, src e tests existentes.
- Documentos de planejamento preservados.
- package.json preservado.
- Nenhum arquivo de código criado antecipadamente.

## 6. Resultado esperado

Estrutura de diretórios preparada para receber os módulos e recursos da aplicação.
