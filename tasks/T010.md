# T010 — Criar estrutura de tabelas SQLite

**Etapa:** P03 — Persistência SQLite  
**Status inicial:** Pendente

## Objetivo

Criar as tabelas necessárias para armazenar os dados persistentes do Mini Agent.

## Atividades

1. Criar a tabela `projects` para registrar projetos.
2. Criar a tabela `sessions` para registrar sessões de interação.
3. Criar a tabela `messages` para armazenar mensagens das sessões.
4. Criar a tabela `operations` para registrar operações do agente.
5. Definir chaves primárias e estrangeiras.
6. Estabelecer os relacionamentos entre as tabelas.
7. Implementar a criação automática das tabelas na inicialização do banco.

## Critérios de conclusão

- As quatro tabelas são criadas automaticamente.
- Cada tabela possui uma chave primária.
- As relações entre projetos, sessões, mensagens e operações estão definidas.
- As chaves estrangeiras estão habilitadas.
- A inicialização pode ser executada repetidamente sem duplicar ou apagar estruturas existentes.
