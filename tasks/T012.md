# T012 — Persistência de mensagens

**Etapa:** P03 — Persistência SQLite  
**Status inicial:** Pendente

## Objetivo

Implementar operações para armazenar e recuperar mensagens das sessões de interação do Mini Agent.

## Atividades

1. Criar a função `saveMessage()` para registrar mensagens.
2. Validar os dados obrigatórios.
3. Verificar se a sessão informada existe.
4. Criar a função `listMessages()` para recuperar o histórico de uma sessão.
5. Ordenar as mensagens cronologicamente.
6. Tratar erros de persistência.

## Critérios de conclusão

- É possível registrar mensagens no banco.
- Mensagens possuem identificação de sessão e papel (`system`, `user`, `assistant` ou `tool`).
- Mensagens sem conteúdo ou sessão válida são rejeitadas.
- É possível recuperar o histórico de uma sessão.
- As mensagens são apresentadas na ordem de registro.
- Os dados permanecem disponíveis após encerrar e reabrir a conexão.
