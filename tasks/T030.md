# T030 — Implementar execução de ferramentas de leitura

**Etapa:** P06 — Núcleo do agente  
**Status:** Concluída

## Objetivo

Implementar o módulo responsável por executar as operações automáticas de leitura solicitadas pelo modelo, utilizando as funções existentes em `files.js`.

## Escopo

Criar o módulo `src/tools.js`, responsável por:

1. Receber uma operação previamente interpretada pelo módulo `operations.js`.
2. Identificar o projeto pelo seu identificador.
3. Recuperar o diretório raiz autorizado por meio de `getProject()`.
4. Encaminhar a operação e seus argumentos à função correspondente de `files.js`.
5. Retornar o resultado da execução.
6. Rejeitar operações não permitidas ou solicitações inválidas.

## Operações disponíveis

| Operação | Função de destino |
|---|---|
| `list_files` | `listFiles()` |
| `search_files` | `searchFiles()` |
| `read_file` | `readFile()` |

## Responsabilidades

- Validar os dados recebidos.
- Aceitar somente operações classificadas como automáticas.
- Aceitar somente solicitações do tipo `tool_call`.
- Recuperar o projeto pelo identificador.
- Utilizar o `root_path` cadastrado como diretório autorizado.
- Preservar os mecanismos de validação e segurança de `files.js`.
- Retornar os resultados das operações.

## Arquivos envolvidos

**Criar:**
- `src/tools.js`
- `tests/tools.test.js`

**Reutilizar:**
- `src/operations.js`
- `src/files.js`
- `src/database.js`

## Critérios de aceitação

- Executar corretamente `list_files`.
- Executar corretamente `search_files`.
- Executar corretamente `read_file`.
- Utilizar o diretório raiz do projeto cadastrado.
- Rejeitar identificadores de projeto inválidos ou inexistentes.
- Rejeitar operações que exigem aprovação.
- Rejeitar respostas que não representem solicitações automáticas.
- Preservar as restrições de acesso aos arquivos.
- Possuir testes automatizados para as operações e situações de erro.
- Não realizar alterações nos arquivos do projeto.

## Limites

Esta tarefa não contempla:

- Integração da execução ao módulo `agent.js`.
- Repetição de consultas ao modelo.
- Implementação do ciclo de execução.
- Execução de operações de criação ou substituição de arquivos.
- Controle de quantidade de iterações.

Essas responsabilidades pertencem às tarefas T031 e T032.
