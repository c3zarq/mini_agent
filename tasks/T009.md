# T009 — Configurar banco SQLite

**Etapa:** P03 — Persistência SQLite  
**Status inicial:** Pendente

## Objetivo

Implementar a conexão entre o Mini Agent e o banco de dados SQLite, utilizando a biblioteca better-sqlite3.

## Atividades

1. Criar o módulo `src/database.js`.
2. Definir o diretório de armazenamento `~/.mini-agent/`.
3. Criar automaticamente o diretório caso não exista.
4. Configurar a abertura do banco `agent.db`.
5. Exportar a conexão para utilização pelos demais módulos.
6. Implementar uma função para encerrar a conexão com o banco.

## Critérios de conclusão

- O módulo estabelece conexão com SQLite.
- O diretório de armazenamento é criado automaticamente.
- O arquivo `agent.db` é criado automaticamente.
- A conexão pode ser utilizada por outros módulos.
- A conexão pode ser encerrada corretamente.
