# T011 — Cadastro e gerenciamento de projetos

**Etapa:** P03 — Persistência SQLite  
**Status inicial:** Pendente

## Objetivo

Implementar operações básicas para cadastrar e consultar projetos no banco de dados do Mini Agent.

## Atividades

1. Criar a função `createProject()` para cadastrar projetos.
2. Validar os dados obrigatórios do projeto.
3. Impedir o cadastro de projetos com caminhos já registrados.
4. Criar a função `listProjects()` para listar os projetos cadastrados.
5. Criar a função `getProject()` para consultar um projeto pelo identificador.
6. Tratar erros de banco de dados.

## Critérios de conclusão

- É possível cadastrar um projeto.
- Projetos sem nome ou caminho são rejeitados.
- Caminhos duplicados são rejeitados.
- É possível listar os projetos cadastrados.
- É possível consultar um projeto pelo identificador.
- Os dados permanecem disponíveis após encerrar e reabrir a conexão.
