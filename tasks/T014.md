# T014 — Implementar cadastro de projetos

**Etapa:** P04 — Gerenciamento de projetos e tarefas  
**Status:** Concluída

## Objetivo

Implementar a funcionalidade de cadastro de projetos no Mini Agent, permitindo associar a aplicação a diretórios de projetos existentes no sistema de arquivos.

## Atividades

1. Validar o nome e o caminho informado para o projeto.
2. Verificar a existência e o tipo do diretório.
3. Registrar o projeto no SQLite.
4. Tratar erros de cadastro e caminhos duplicados.

## Implementação

Criado o módulo `src/projects.js`, responsável pelo gerenciamento do cadastro de projetos.

Função implementada:

- `registerProject()`: recebe nome e caminho do projeto, valida os dados, verifica a existência do diretório e utiliza `createProject()` para persistir o registro no SQLite.

Recursos utilizados:

- `node:fs`: verificação do sistema de arquivos.
- `node:path`: resolução de caminhos absolutos.
- `src/database.js`: persistência dos projetos.

## Testes 

- Cadastro de projeto com diretório válido.
- Rejeição de nome vazio.
- Rejeição de caminho vazio.
- Rejeição de diretório inexistente.
- Rejeição de caminhos duplicados.
- Rejeição de caminhos que correspondem a arquivos.
- Recuperação dos projetos cadastrados por meio de `listProjects()`.

## Critérios de conclusão

Todos os critérios foram atendidos. É possível cadastrar projetos associados a diretórios existentes, validar os dados informados e recuperar os registros persistidos no SQLite.
