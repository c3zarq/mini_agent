# T003 — Configurar ambiente e dependências

**Etapa:** P01 — Estrutura inicial<br>
**Dependências:** T001 e T002<br>
**Status inicial:** Pendente

## 1. Objetivo

Preparar o ambiente Node.js e instalar as dependências mínimas necessárias ao desenvolvimento do Mini Agent.

## 2. Dependências

Instalar:

- better-sqlite3: integração com banco SQLite.

Utilizar recursos nativos do Node.js para:

- Comunicação HTTP (fetch).
- Interface de terminal (readline).
- Testes automatizados (node:test).
- Manipulação de arquivos (fs).

## 3. Configurações

Adicionar ao package.json:

- Script start.
- Script test.
- Dependências do projeto.

## 4. Arquivo .gitignore

Criar arquivo para ignorar:

- node_modules/
- arquivos de banco SQLite;
- arquivos .env;
- logs;
- arquivos temporários.

## 5. Restrições

- Não implementar funcionalidades.
- Não criar módulos JavaScript.
- Não instalar frameworks.
- Não instalar bibliotecas desnecessárias.
- Não alterar a documentação arquitetural.

## 6. Critérios de aceitação

- better-sqlite3 instalado.
- Dependências registradas no package.json.
- Scripts npm configurados.
- .gitignore criado.
- Aplicação reconhece a dependência SQLite.

## 7. Resultado esperado

Ambiente de desenvolvimento preparado para iniciar a implementação dos módulos do Mini Agent.
