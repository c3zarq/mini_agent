# T018 — Implementar carregamento de tarefas

**Etapa:** P04 — Gerenciamento de projetos e tarefas  
**Status:** Concluida

## Objetivo

Implementar a leitura e interpretação dos documentos individuais de tarefas em Markdown, permitindo que o Mini Agent identifique suas informações e estrutura automaticamente.

## Atividades

1. Definir a estrutura de dados utilizada para representar uma tarefa interpretada.
2. Implementar a localização e leitura dos documentos individuais utilizando `node:fs`.
3. Identificar o código e o título da tarefa.
4. Identificar a etapa correspondente.
5. Identificar o status documentado.
6. Interpretar as seções de objetivo, atividades, critérios de conclusão, restrições, implementação e testes.
7. Validar a estrutura do documento e identificar informações obrigatórias ausentes.
8. Implementar o tratamento de erros de leitura e interpretação.
9. Criar testes automatizados para verificar o carregamento das tarefas.

## Critérios de conclusão

- A aplicação consegue localizar e ler documentos individuais de tarefas.
- O código e o título da tarefa são identificados corretamente.
- A etapa e o status são identificados.
- As seções do documento são interpretadas corretamente.
- Seções opcionais podem estar ausentes.
- Documentos com estrutura inválida são identificados.
- Arquivos inexistentes ou inacessíveis produzem mensagens de erro apropriadas.
- Os testes automatizados são aprovados.

## Restrições

- A implementação deverá respeitar o formato definido em `tasks/TEMPLATE.md`.
- A leitura deverá utilizar o módulo nativo `node:fs`.
- Esta tarefa não deverá cadastrar ou atualizar informações no SQLite.
- A sincronização entre documentos de tarefas e banco de dados será implementada na T019.

## Implementação

Criado o módulo `src/tasks.js`, responsável pela leitura, interpretação e validação dos documentos individuais de tarefas.

Funções implementadas:

- `readTask()`: leitura de arquivos Markdown utilizando `node:fs`.
- `parseTaskHeader()`: identificação do código e título.
- `parseTaskMetadata()`: identificação da etapa e do status.
- `parseTaskSections()`: interpretação das seções do documento.
- `validateTask()`: validação da estrutura e das seções obrigatórias.
- `parseTask()`: interpretação completa e organização dos dados em um objeto JavaScript.

Criada a suíte automatizada `tests/tasks.test.js`.
