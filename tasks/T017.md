# T017 — Definir modelo de documento de tarefa

**Etapa:** P04 — Gerenciamento de projetos e tarefas  
**Status:** Concluída

## Objetivo

Definir um template Markdown padronizado para os documentos individuais de tarefas do Mini Agent, permitindo sua identificação, documentação e interpretação automatizada.

## Atividades

1. Analisar os documentos de tarefas existentes.
2. Identificar as seções comuns e necessárias.
3. Definir a estrutura padronizada do documento.
4. Estabelecer seções obrigatórias e opcionais.
5. Criar o template de referência.

## Critérios de conclusão

- Existe um template Markdown padronizado.
- O modelo contempla identificação, etapa, status e objetivo.
- O modelo contempla atividades e critérios de conclusão.
- O modelo permite registrar implementação e testes.
- As seções opcionais podem ser omitidas quando não aplicáveis.
- O modelo é compatível com a arquitetura do Mini Agent.

## Implementação

- Analisados os documentos T014, T015 e T016.
- Definida a estrutura padronizada dos documentos individuais.
- Criado o arquivo `tasks/TEMPLATE.md`.
- Estabelecidas seções obrigatórias e opcionais.
- Mantida a separação entre documentação das tarefas e estado de execução armazenado no SQLite.
