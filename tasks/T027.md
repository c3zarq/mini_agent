# T027 — Implementar protocolo JSON

**Etapa:** P06 — Núcleo do agente  
**Status:** Concluída

## Objetivo

Implementar um módulo responsável por validar as respostas estruturadas produzidas pelo modelo, garantindo que estejam de acordo com o protocolo JSON definido na arquitetura do Mini Agent.

## Escopo

Criar o módulo `src/protocol.js`, responsável por reconhecer e validar os três tipos de resposta previstos:

### 1. Solicitação de ferramenta (`tool_call`)

Campos obrigatórios:
- `type`: string com valor `tool_call`;
- `name`: identificação da ferramenta;
- `arguments`: objeto com os argumentos da operação.

### 2. Proposta de alteração (`proposal`)

Campos obrigatórios:
- `type`: string com valor `proposal`;
- `name`: identificação da operação;
- `arguments`: objeto com os argumentos da alteração;
- `message`: descrição da proposta.

### 3. Resposta final (`final`)

Campos obrigatórios:
- `type`: string com valor `final`;
- `message`: conteúdo da resposta final.

## Responsabilidades

- Validar a estrutura das respostas recebidas.
- Identificar os tipos de resposta reconhecidos.
- Verificar a presença e o tipo dos campos obrigatórios.
- Rejeitar tipos de resposta desconhecidos.
- Retornar resultados padronizados de validação.
- Não executar operações nem modificar arquivos.

## Arquivos previstos

- `src/protocol.js`
- `tests/protocol.test.js`

## Critérios de aceitação

- Os três tipos de resposta definidos na arquitetura são reconhecidos.
- Respostas com estrutura válida são aceitas.
- Respostas com campos obrigatórios ausentes são rejeitadas.
- Respostas com tipos de dados incompatíveis são rejeitadas.
- Tipos de resposta desconhecidos são rejeitados.
- A validação não executa operações solicitadas pelo modelo.
- Os testes automatizados cobrem os casos válidos e inválidos.

## Testes

Executar:

```bash
node --test tests/protocol.test.js
```

E, após a implementação:

```bash
npm test
```

## Resultado esperado

O Mini Agent dispõe de um módulo independente para validar respostas estruturadas, estabelecendo uma interface confiável entre as respostas do modelo e as etapas posteriores de interpretação e execução.

## Limites da tarefa

Esta tarefa não contempla:

- Integração do protocolo ao fluxo de comunicação com Ollama (T028).
- Interpretação semântica das operações (T029).
- Execução de ferramentas (T030).
- Controle do ciclo de execução (T031).
- Tratamento dos limites de execução e falhas do agente (T032).
