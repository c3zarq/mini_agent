# T006 — Listar modelos disponíveis no Ollama

**Etapa:** P02 — Integração com Ollama  
**Status inicial:** Pendente

## Objetivo

Implementar a consulta aos modelos disponíveis localmente no servidor Ollama.

## Escopo

1. Adicionar a função `listModels()` ao módulo `src/ollama.js`.
2. Consultar o endpoint HTTP `GET /api/tags`.
3. Interpretar a resposta JSON.
4. Retornar a relação de modelos disponíveis.
5. Tratar falhas de comunicação, respostas HTTP inesperadas e respostas inválidas.
6. Preservar a função `checkConnection()` existente.

## Critérios de aceitação

- A função consulta corretamente o endpoint `/api/tags`.
- A resposta é interpretada como JSON.
- Os modelos são retornados em uma estrutura acessível pelo restante da aplicação.
- Falhas são tratadas sem provocar encerramento inesperado.
- O módulo permanece compatível com CommonJS.
- Não são adicionadas dependências externas.

## Fora do escopo

- Seleção de modelo.
- Envio de mensagens.
- Execução de conversas.
- Instalação ou remoção de modelos.
