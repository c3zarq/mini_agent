# T005 — Implementar conexão com Ollama

**Etapa:** P02 — Integração com Ollama  
**Status inicial:** Pendente

## Objetivo

Implementar a comunicação básica entre a aplicação Mini Agent e o servidor local Ollama, utilizando a API HTTP disponibilizada pelo serviço.

## Escopo

1. Criar o módulo `src/ollama.js`.
2. Implementar uma função para verificar a conexão com o servidor Ollama.
3. Utilizar a API HTTP local, com endereço padrão `http://localhost:11434`.
4. Utilizar o recurso `fetch` nativo do Node.js.
5. Tratar falhas de conexão e respostas HTTP inesperadas.
6. Exportar a função para utilização pelos demais módulos.

## Critérios de aceitação

- A aplicação consegue consultar o servidor Ollama.
- A conexão é identificada corretamente quando o serviço está disponível.
- Falhas de conexão são tratadas sem interromper inesperadamente a aplicação.
- O módulo utiliza CommonJS.
- Não são instaladas dependências externas adicionais.

## Fora do escopo

- Listagem de modelos.
- Envio de mensagens aos modelos.
- Histórico de conversas.
- Processamento de respostas JSON.
