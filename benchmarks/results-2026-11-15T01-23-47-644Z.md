Algoritmo seguro de validação de caminhos em Node.js:

1. Receba o caminho solicitado como entrada.
2. Converta o caminho em um objeto `path` usando `path.resolve()`.
3. Normalize o caminho usando `path.normalize()`.
4. Verifique se o caminho absoluto está dentro do diretório raiz autorizado. Se não, rejeite.
5. Se o caminho for relativo, converta-o para um caminho absoluto usando o diretório raiz autorizado como ponto de partida.
6. Verifique se o caminho contém "../" ou "..", o que pode levar a acesso indesejado. Se estiver, rejeite.
7. Se o caminho for um link simbólico, resolva-o para o caminho real usando `path.resolve()`.
8. Compare o nome do diretório do caminho solicitado com o diretório raiz autorizado. Se corresponder, verifique se é um subdiretório. Se não for um subdiretório, rejeite.
9. Se passar todas as verificações, autorize o caminho.
